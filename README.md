# 🚲 Design and Analysis of Bicycle Frame
## 📌 Overview
This project aims to design and evaluate the structural performance of a bicycle frame using modern CAD and FEA tools. The analysis was conducted to optimize the frame’s strength, safety, and weight for real-world cycling scenarios using SolidWorks and ANSYS.

## 🎯 Objectives
+ Design a structurally sound bicycle frame with lightweight geometry.

+ Validate the frame under multiple loading conditions using FEA.

+ Ensure all stress levels remain below material yield strength for rider safety.

+ Identify potential for material optimization and weight reduction.

## 🛠️ Tools & Technologies
+ CAD Software: SolidWorks 2022

+ Simulation Software: ANSYS Mechanical (FEA)

+ Material Used: Aluminum Alloy 6061-T6

+ Young’s Modulus: 68.9 GPa

+ Yield Strength: 276 MPa

+ Ultimate Tensile Strength: 310 MPa

## 🔬 Analysis Scenarios
Three structural test cases were simulated:

| Test Case        | Force Applied           | Max Stress (MPa) | Deformation (mm) | Factor of Safety |
| ---------------- | ----------------------- | ---------------- | ---------------- | ---------------- |
| **Front Impact** | 1200N on handlebar      | 43.24            | 0.47             | 6.47             |
| **Static Start** | 500N on pedal crank     | 6.52             | 0.035            | 15.0             |
| **Steady State** | 700N rider + 200N pedal | 44.53            | 0.088            | 6.28             |

## 📈 Key Insights
+ The design withstood all loads with FOS > 6, indicating high reliability.

+ Maximum deformation: 0.47 mm, ensuring good stiffness and rider comfort.

+ ANSYS FEA confirmed all stresses were far below the yield strength (276 MPa).

+ Potential for weight reduction without compromising structural safety.
